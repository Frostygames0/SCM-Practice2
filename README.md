# PackageMan — визуализатор графа зависимостей для пакетов AlpineLinux
## Описание
Это простой визуализатор графа зависимостей менеджера пакетов для **Alpine Linux**\
Написан используя **C++23, curl, libarchive, reproc++**.\
Использует **mermaid** для визуализации графа.

## Текущий фукнционал
- Работает с двумя видами репозиториев: тестовыми и удаленными
- Может зафетчить любой доступный в сети совместимый с **apk репозиторий** и выгрузить индекс оттуда
- Затем он может построить граф зависимостей выбранного пакета

## Сборка
**Требования:**
- любой компилятор для ОС Linux или ОС Windows, поддерживающий стандарт C++23 (Например: GCC, MSVC или Clang) 
- CMake >=3.28 - система сборки
- Ninja (рекомендуется и требуется run.sh/bat)
- curl (libcurl) - любая не древняя версия
- libarchive - также любая не древняя версия

Для сборки достаточно запустить файлы описанные ниже в разделе "Запуск"

## Запуск
**Программа:** Для запуска программы достаточно запустить run.sh / run.bat с аргументами программы\
**Тесты:** Для запуска теста(ов) запустите файл runtests.sh (bat) в зависимости от вашей ОС
