# PackageMan — визуализатор графа зависимостей для пакетов AlpineLinux
## Описание
Это простой визуализатор графа зависимостей менеджера пакетов для Alpine Linux
Написан используя C++ и mermaid в качестве визуализатора графа
## Текущий фукнционал
- Принимает конфигурацию через аргументы комадной строки
- Проверяет их на корректность
- Выводит их

## Сборка и запуск
**Требования:** компилятор C++23 (GCC, MSVC, Clang и подобные), Ninja (рекомендуется)
